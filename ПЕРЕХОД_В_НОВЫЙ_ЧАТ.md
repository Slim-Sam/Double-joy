## 1. Что это за проект

**Продукт:** APK «Двойная_радость_Автозахват.apk» — решалка (автозахват) для мини-игры «Двойная радость» в игре Last Asylum: Plague (`com.phs.global`).

**Финальная сборка:** v1.0.34 (982 КБ, подписана v2+v3, 100% офлайн).

**Что делает приложение:** плавающее окно на телефоне (MediaProjection) снимает экран, движок компьютерного зрения (CV) распознаёт гекс-поле, стопки, руку, счёт, этапы; решатель (нативный Java `SolverEngine.java`) выдаёт оптимальные ходы. Полная офлайн-работа, без INTERNET-разрешения.

**Источники знаний (если нужен глубокий контекст):** `СОСТОЯНИЕ_ПРОДОЛЖЕНИЯ.md`, `ИСТОРИЯ_ОБЩЕНИЯ.md` (полная хронология с самого начала), `ЗАДАЧИ_*.md`.

## 9. Технические ограничения (кратко)

- **НЕ** строить APK без явного подтверждения.
- **НЕ** использовать `btnRandomHand` как истину о логике игры — это решалка.
- **НЕ** использовать `javac` с кириллицей без `LC_ALL=C.UTF-8` и `-encoding UTF-8`.
- **НЕ** использовать `org.json.JSONObject` в android.jar на desktop JVM (Stub!).
- **НЕ** использовать CLI `unzip` с UTF-8 кириллицей — Python `zipfile`.
- **НЕ** заменять `cx0 = 0.5*(xLeft+xRight)` в `fitBoardCamera`; держать 540px.
- Beam search (beamWidth 40, rounds 10) **таймаутится на 300s**.
- Wave elimination: `ELIMINATE_NUM = 10`, не `topCount >= 3`.
- **НЕ** использовать single-byte XOR на XLua bytecode; **НЕ** прямой LZ4 на остатке Lua-bundle.
- **НЕ** использовать `obj.get_raw_data()` для `basedata_jit` (XLua bytecode) — только для языковых/gamedata bundles.
