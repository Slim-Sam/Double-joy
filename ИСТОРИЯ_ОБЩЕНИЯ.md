## 3. Превышение лимита рабочего пространства

**Сообщение системы:** «Рабочее пространство превышает бюджет. В ходе этой сессии было создано 2323,2 МБ файлов общей длиной 506 файлов, что превышает лимит в 128 МБ на 10 000 файлов. 435 файлов не были сохранены.»

**Причина:** Lокальное рабочее пространство накопило 2.4 ГБ тяжёлых файлов.

**Разбор по категориям:**
| Папка | Размер | Что это |
|---|---|---|
| `last_asylum_121` | 485 МБ | Извлечённые данные игры |
| `last_asylum_game` | 186 МБ | Извлечённые данные игры |
| `.git` | 105 МБ | git-история (включала мусорные объекты) |
| `.cache` | 93 МБ | pip-кэш |
| `uploads` | 22 МБ | Загруженные пользователем файлы |
| `.npm` | 19 МБ | npm-кэш |
| `frame_delta_emu` | 3 МБ | Рабочий эмулятор |

**Очистка:**
- Удалены: `last_asylum_121`, `last_asylum_game`, `.cache`, `.npm`, `uploads`, `frame_delta_emu`, `stage_emu_11_16`, XAPK-инсталляторы
- **Важно:** весь код решалки уже на GitHub, тяжёлые файлы и не были в репозитории (через `.gitignore`)

**Проблема с `.git`:** 105 МБ мусорных git-объектов из начального `git add` (403 dangling-объекта, 103 МБ).
**Решение:** `git reflog expire --expire=now --all` + `git gc --prune=now --aggressive` → `.git` сократился 105 МБ → **4.4 МБ**.

**Итог:** Workspace сокращён 2.4 ГБ → **12 МБ** (в 10× под лимитом).

## 8. Запрос о Solver Web UI

**Вопросы пользователя:**
- «Solver Web UI что это?»
- «А он вообще нужен для APK?»
- «Ты можешь отделить постностью APK от Solver Web UI»
- «Удали»

**Разъяснение:**
- **HTML-интерфейс** (`solver.html`) — **нужен APK** (это экран управления, грузится через `file:///android_asset/solver.html` в WebView)
- **`app.py`** (FastAPI, порт 8000) — **не нужен APK**, только инструмент разработчика

**Разделение:**
- `app.py` перемещён в отдельный каталог `solver_web_ui/`
- APK-сборка (`build_apk.sh`, `make_apk_html.py`) не зависит от веб-UI
- Пути обновлены в `СОСТОЯНИЕ_ПРОДОЛЖЕНИЯ.md`
- Commit: `Separate Solver Web UI from APK project`

**Удаление:**
- `solver_web_ui/` полностью удалён
- APK остаётся самодостаточным
- Commit: `Remove Solver Web UI (solver_web_ui/app.py) — APK is fully standalone`

**Проблема с портом 8000:**
- **Причина:** Старый процесс `solver-web-ui-5492a139` (PID 33979) до сих пор слушал порт 8000 — «зомби-процесс» (uvicorn запущен, но `app.py` удалён)
- **Решение:** Процесс остановлен через `stop_process`
- **Итог:** Порт 8000 свободен, красный пропал

## 10. Ограничение зрения и пути решения

**Факт:** Текущая модель **не обладает зрением** — не может анализировать изображения.

**Проверено:**
- ❌ `read_file` на изображении → `[An image was provided here, but you do not have vision capabilities.]`
- ❌ Стандартный метод чтения изображений → не работает
- ✅ Цифровой анализ (разрешение, яркость, палитра, MD5) → работает
- ✅ Текст лога → читается полностью

**Предложенные решения:**
1. **OCR** — читает текст с скриншотов (UI, счёт, названия карт). Нужно установить tesseract.
2. **Облачный vision-API** — отправляет снимок модели с зрением, получает полное описание. Нужен API-ключ.
3. **Описание текстом** — пользователь кратко описывает снимок, я анализирую по контексту.

**Начата установка OCR** через `apt-get download` (без root) — процесс был прерван при загрузке зависимостей.
